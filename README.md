# ADA 2026 — US macro regimes: econometrics vs machine learning (Danny Alfallouji)

Can machine learning identify and predict US recessions better than classical
econometric models? Markov-switching, Sahm rule and yield-curve probit vs. PCA,
random forests and neural networks.

## Install

```bash
pip install -r requirements.txt
```

No API key is needed.

## Run, in order

| Step | Command | Time | Produces |
|---|---|---|---|
| 1. Get the data | `python code/01_get_data.py` | ~1 min | `data/raw/` |

## Data: sources and licences

| Data | Source | Licence | In this repository? |
|---|---|---|---|
| 29 macro and financial series (list and roles in `code/01_get_data.py`) | [FRED](https://fred.stlouisfed.org), St. Louis Fed | Mostly public domain; some series are third-party copyright (Moody's BAA/AAA, Cboe VIX, NASDAQ, University of Michigan sentiment) | No — regenerated by step 1 |
| NBER recession dates (`USREC`) | NBER via FRED | Public | No — regenerated by step 1 |
| Monthly S&P 500 price, dividends, earnings, CAPE | [Robert Shiller, Yale](http://www.econ.yale.edu/~shiller/data.htm) | Freely available for research | No — regenerated by step 1 |

Known limits of the raw data, to be handled in the cleaning stage:

- **Mixed frequencies**: monthly, weekly (claims, NFCI) and daily (VIX,
  NASDAQ, spreads, dollar) series.
- **Missing values**: October 2025 is missing for unemployment, CPI and the
  Sahm rule (US federal government shutdown); consumer sentiment is quarterly
  before 1978; daily series are missing on market holidays.
- **Different start dates**: from 1919 to 2006. Real manufacturing and trade
  sales, needed by the Chauvet model, start in 1967.
- **Discontinued series**: the major-currency dollar index ends in 2019 and
  is replaced by the broad index from 2006.
- **Shiller's data end in September 2023.**
- **Revisions**: FRED gives the latest revised values, not what was known at
  the time. Real-time vintages (ALFRED) are needed for an honest real-time
  evaluation.
- Only 9 NBER recessions since 1959 (11.7% of months).
